Homeboard privacy policy

Last updated: September 20, 2026. Back to Homeboard

What Homeboard is

Homeboard is a personal home dashboard that runs on the owner's own Raspberry Pi. There is no Homeboard website or server that collects data from users.

What data it accesses

When the owner signs in with Google, Homeboard requests two read-only permissions: view calendars (Google Calendar) and view tasks (Google Tasks). It reads event titles and times and task titles and due dates so they can be shown on the owner's screen.

How the data is used and stored

The calendar and task information is shown only on the screen and the private dashboard of the Raspberry Pi it was read on. The sign-in token that Google issues is stored as a file on that same Raspberry Pi. Homeboard does not send your Google data to the developer, to any other server, or to any third party. It does not sell or share data, does not use it for advertising, and does not use analytics or tracking.

Weather

To show the weather, Homeboard sends the latitude and longitude of the owner's chosen city to Open-Meteo.com. No Google data is sent there.

Google API Services User Data Policy

Homeboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting your data and revoking access

You can remove Homeboard's access at any time at myaccount.google.com/permissions. Deleting the Homeboard folder on the Raspberry Pi (or using Disconnect in its dashboard) also removes the stored sign-in token.

Contact

Questions about this policy can be sent to the support email address shown on the app's Google sign-in screen.
